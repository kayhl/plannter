# Plannter

Allows you to select vegetables you want to grow and tells you when to plant and when to harvest. It was created to make garden planning ADHD-friendly.

## Features

- Plan from a desired starting date
- Plan backward from a desired harvest date
- Coordinate harvests for canning
- Exports as PDF files

## Requirements

- Python 3.11+
- [customtkinter](https://customtkinter.tomschimansky.com/) - GUI
- [fpdf2](https://py-pdf.github.io/fpdf2/) - PDF export

## Installation

```bash
git clone https://github.com/kayhl/plannter
cd plannter
pip install customtkinter
pip install fpdf2
```
## Usage

```python main.py```
